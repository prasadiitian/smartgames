# Playgama submission

**Title:** Bondwork
**Genre:** Idle / Clicker / Casual (secondary: Educational, Simulation)
**Languages:** English
**Platforms:** Mobile and desktop browsers, portrait and landscape, runs in a 16:9 iframe
**Orientation:** Both
**Build:** `deploy/builds/bondwork-v1.1.0-*.zip` (index.html at root, ~87 KB unzipped, no external requests)
**Covers:** `covers/` (315x250, 630x500, 1280x720). **Screenshots:** `screenshots/`.
**Ads/SDK:** Ships with a no-op platform adapter (`src/platform.js`). Playgama Bridge will be added after account approval; rewarded hooks already exist for "2x production" and "2x offline earnings".
**Monetization:** none at launch.

**Short description:** Idle game about building matter. Balance real chemical reactions to make water, methane, ammonia and glucose.

**Long description:** Spark atoms, bond them in reactors, and balance the ratio dials to match real equations. Watch molecules bond and pile up, stabilise (or gamble on) unstable reactions, catch rare lucky bonds, unlock new compounds, and Phase Change for permanent power. Offline progress up to 8 hours, save export/import, colourblind-friendly colours.

**Controls:** tap/click only.
**Tags:** idle, incremental, chemistry, science, casual, clicker, relaxing
